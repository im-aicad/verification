# 车轮罩项目开发文档

# 1. 项目概述

## 1.1 项目背景

车轮罩法规校核涉及车轮装配、轮胎识别、轮罩与轮胎空间匹配、轮罩包围盒、轮罩到轮胎轴线距离、截面轮廓高度、法规标注、截图和报告整理。传统人工流程需要在 CATIA 中反复装配、隐藏无关零件、测量包围盒、创建截面、取极值点、手动标注并整理报告，步骤多且结果容易受操作习惯影响。

本项目通过本地 Web 工作台、FastAPI 后端、子进程隔离和 CATIA COM 自动化脚本，将车轮罩法规校核流程工程化。用户在浏览器中上传 1-4 个轮罩 CATPart 和车轮装配文件夹，系统自动连接 CATIA，创建校核总成，筛选 Tire 代表件，生成法规轴线与截面，创建标注和截图，最终输出 CATProduct、过程 CATPart、JSON 结果和 Word 报告。

## 1.2 项目目标

- 支持左前、右前、左后、右后 1-4 个轮罩输入，未输入轮罩不参与报告。
- 支持车轮装配文件夹上传并指定根 CATProduct。
- 自动过滤隐藏零件，仅对显示零件进行重心、候选筛选和包围盒分析。
- 通过轮罩重心和 400mm 近邻逻辑筛选车轮装配内相关零件。
- 从轮胎候选中选择 Tire 代表件，并与轮罩匹配。
- 自动生成法规轴线、0deg/30deg 截面平面、轮罩包围盒线框和截面结果。
- 在测量过程中即时创建标注、截图，并在截图后隐藏当前标注，最终恢复显示。
- 生成法规测量表、法规对比表和截图 Word 报告。
- 支持 PyInstaller 打包为单 exe 服务。

# 2. 系统架构

系统采用本地单机 Web 服务架构。前端页面运行在浏览器中，后端 FastAPI 服务运行在本机，通过 COM 接口驱动同机 CATIA V5。算法在独立 worker 子进程中执行，避免 CATIA 或 COM 异常直接拖垮 Web 服务。

| 架构层次 | 组件说明 |
|---|---|
| 前端层 | `wheel_trim/web/index.html`，单页面工作台，负责文件选择、CATIA 状态、日志助手、画面捕获、版本库和结果保存。 |
| API 服务层 | `wheel_trim/server/server.py`，FastAPI 服务，负责上传、状态、下载、报告生成和 WebSocket 日志。 |
| 子进程隔离层 | `wheel_trim/server/run_algorithm_worker.py`，负责加载算法模块、初始化 COM、执行检测并写回 JSON。 |
| 算法层 | `wheel_trim/server/pycatia_wheelhouse_regulation_verification/main.py`，核心 CATIA 自动化和几何算法。 |
| 通用工具 | `catia_annotation_tools.py` 标注工具，`catia_picture_capture.py` 截图工具，`section_curve_export_tool.py` 截面导出工具。 |
| 输出层 | CATProduct、过程 CATPart、标注 CATPart、截图、JSON 结果和 Word 报告。 |

# 3. 输入与输出

## 3.1 输入文件

| 输入项 | 规格 |
|---|---|
| 左前轮罩 | 可选 `.CATPart` |
| 右前轮罩 | 可选 `.CATPart` |
| 左后轮罩 | 可选 `.CATPart` |
| 右后轮罩 | 可选 `.CATPart` |
| 车轮装配 | 必填文件夹，需指定根 `.CATProduct` |

至少上传一个轮罩。前端和后端都会校验文件类型，轮罩必须是 `.CATPart`，车轮装配根节点必须是 `.CATProduct`。

## 3.2 报告参数

| 参数 | 用途 |
|---|---|
| 轮胎半径 r | 用于法规对比 `c < 2r`。 |
| 轮胎 Y 向宽度 b | 用于法规对比 `q > b`。 |

## 3.3 输出文件

输出根目录为 `output/output-时间戳/result-时间戳/`。

| 输出项 | 说明 |
|---|---|
| `wheelhouse_regulation_verification_时间戳.CATProduct` | 校核总成结果。 |
| `Wheelhouse_Regulation_Axis_Lines_时间戳.CATPart` | 过程 Part，包含法规轴线、截面平面和包围盒线框。 |
| `Wheelhouse_Regulation_Annotations.CATPart` | 标注 Part，包含法规测量点线。 |
| `wheelhouse_regulation_verification_result_时间戳.json` | 完整检测数据。 |
| `wheelhouse_regulation_report_时间戳.docx` | Word 法规检测报告。 |
| `screenshots/*.png` | 各项测量截图。 |

# 4. 核心流程

## 4.1 前端日志流程

前端日志助手展示 11 步状态：

| 步骤 | 名称 |
|---|---|
| 第 1 步 | 连接 CATIA |
| 第 2 步 | 打开输入文件 |
| 第 3 步 | 筛选轮胎候选 |
| 第 4 步 | 匹配轮罩和车轮 |
| 第 5 步 | 创建轴线和切割面 |
| 第 6 步 | 获取轮罩包围盒 |
| 第 7 步 | 截面导出与极值点线 |
| 第 8 步 | 法规距离测量 |
| 第 9 步 | 法规标注 |
| 第 10 步 | 法规截图 |
| 第 11 步 | 保存校核结果 |

前端通过 WebSocket 接收后端日志，并根据关键词推进步骤状态。

## 4.2 文件上传与 worker 调用

`/verify` 接口接收轮罩文件、车轮装配文件夹、根装配路径、轮胎半径 r 和轮胎宽度 b。服务端保存上传文件后，通过 `run_algorithm_sync()` 启动 worker。

源码运行时 worker 命令为：

```text
python run_algorithm_worker.py <左前> <右前> <左后> <右后> <车轮根装配> <结果JSON> <输出目录>
```

打包 exe 运行时使用同一 exe 的 `--wheelhouse-worker` 模式启动子进程。

## 4.3 CATIA 装配和根节点居中

算法启动后连接或启动 CATIA，创建新的校核 CATProduct，将实际输入的轮罩和车轮装配根节点装入。装配后执行根节点居中，方便用户查看新建总成。

## 4.4 Tire 候选识别

算法遍历车轮装配下显示状态的叶子零件。隐藏零件会被跳过，并写入结果中的隐藏跳过列表。

候选识别综合使用：

- 圆线拓扑识别轮胎环形特征。
- 显式轴线或轴系统作为辅助信息。
- 包围盒尺寸、体积和对角线。
- 零件名称和 PartNumber 关键词。
- 同轴圆数量和半径层级评分。

无显式轴但圆线拓扑稳定的零件仍可作为 Tire 候选。

## 4.5 轮罩近邻筛选和匹配

算法先测量输入轮罩重心，再获取车轮装配内显示零件重心。一般认为距离轮罩重心 400mm 内的零件属于对应轮罩附近候选组。后续包围盒和 Tire 代表件筛选只对近邻显示零件进行。

Tire 与轮罩匹配使用：

- 轮罩重心到 Tire 重心距离。
- 轮罩重心到 Tire 轴线距离。
- Tire 代表件优先级评分。

匹配结果用于创建对应轮罩的法规轴线段。

## 4.6 法规轴线和切割面

每个匹配成功的轮罩生成一套轴线段和截面平面。多轮罩命名采用 `Left-Front`、`Right-Front`、`Left-Rear`、`Right-Rear` 前缀。

创建内容包括：

- 法规轴线端点。
- 轴线段。
- 0deg 截面平面。
- 30deg 截面平面。
- 拉伸和旋转相关辅助特征。

过程几何保存在 `Wheelhouse_Regulation_Axis_Lines_时间戳.CATPart`。

## 4.7 轮罩包围盒

轮罩包围盒采用远平面极值法，且仅测量可见主体。当前 q 值取包围盒 Y 向宽度。标注点使用 Y 向边的两个端点，优先选择 XYZ 坐标较大的候选边。

## 4.8 截面导出和极值点

截面处理流程：

1. 复制轮罩工作 CATPart 到过程目录。
2. 单独打开该轮罩工作文件。
3. 根据过程 Part 中的截面三点，在轮罩 Part 内重建截面平面。
4. 调用截面工具创建 SectionResult 曲线并导出独立 CATPart。
5. 主程序打开导出的截面 CATPart。
6. 通过几何集名称和截面特征名称精确找到曲线对象。
7. 使用远平面和曲线到平面的最小距离点获取方向极值点。
8. 在截面 CATPart 内创建极值点和辅助连线。
9. 隐藏远平面几何图形集和辅助连线。
10. 保存并关闭截面 CATPart，再装配到校核 Product 中。

截面 p 和 p30 的测量值取两个极值点世界坐标 Z 值差，与标注文本 `Z=xxxmm` 保持一致。

## 4.9 法规测量和判定

| 测量项 | 来源 | 判定 |
|---|---|---|
| `q` | 轮罩包围盒 Y 向宽度 | `q > b` |
| `c` | 轮罩可见主体到 Tire 轴线最小距离 | `c < 2r` |
| `p` | 0deg 截面极值点 Z 差 | `p > 30mm` |
| `p30` | 30deg 截面极值点 Z 差 | `p30 > 30mm` |

报告只生成实际输入轮罩对应的测量项。未输入的右轮罩或左轮罩不会出现在报告中。

## 4.10 标注和截图

项目当前采用“过程中标注和截图”的策略，而不是最后统一创建后再复杂显隐。

每个测量项执行：

1. 创建标注点、线和 3D 文本。
2. 设置 CATIA 视点。
3. 截图保存到 `screenshots`。
4. 隐藏当前标注点、线和文本。

所有截图完成后恢复轮罩、过程 Part、标注 Part、标注点线和文本为显示状态。

标注参数：

| 参数 | 当前值 |
|---|---|
| 标注颜色 | 绿色 |
| 线宽 | 2 |
| 文本字号 | 8 |
| 文本偏移距离 | 150mm |
| 标注 Part | `Wheelhouse_Regulation_Annotations.CATPart` |
| 标注几何集 | `Wheelhouse Regulation Distance Annotations` |

截图参数：

| 类型 | 视线方向 | 上方向 | 视距 |
|---|---|---|---:|
| q | `(0, 0, -1)` | `(-1, 0, 0)` | 5000 |
| c | `(0, -1, 0)` | `(0, 0, 1)` | 5000 |
| p/p30 | `(-1, 0, 0)` | `(0, 0, 1)` | 1000 |

# 5. Word 报告

Word 报告由 `server.py` 生成，包含测量值、法规对比结果和截图。报告生成时会根据 `wheelhouse_inputs` 动态筛选测量键，只展示实际输入轮罩。

截图写入使用 `python-docx`。图片按测量名称顺序追加到报告末尾，采用紧凑布局，避免强制一页一图。

# 10. 后续优化建议

## 10.1 截图视角恢复

当前截图会设置 CATIA 当前视角。后续可在截图前保存用户原始 `Viewpoint3D`，截图后恢复，减少对用户工作状态的影响。

## 10.2 截面极值稳定性

截面极值已经从采样/投影逻辑调整为远平面测距方式。后续可进一步记录每条 SectionResult 曲线的目标对象、曲线长度、极值点来源和测量平面信息，便于异常追踪。

## 10.3 报告样式增强

当前报告已包含测量表、法规对比表和截图。后续可增加彩色 PASS/FAIL 单元格、项目基本信息、输入文件摘要和异常警告汇总。

## 10.4 大装配性能优化

对大型车轮装配，可继续优化显隐判断、近邻零件筛选、包围盒测量缓存和 CATIA Update 次数，减少 COM 调用开销。
