第一部分：创建法规线
1.检查CATIA有没有打开，若没有打开则打开CATIA
2.如果打开了CATIA，判断“读取文件路径”是否加载，判断加载名称是否一致，再判断文件全路径是否一致，如果有一种情况一致，进行关闭该文件重新打开指定文件
3.查找“输入参数”几何集名称判断该几何图形集是否存在，如果不存在，返回失败，终端输出信息，结束程序
4.若查找成功，查找以下特征
左镜片特征名称
右镜片特征名称
左眼点特征名称 
右眼点特征名称
空载地面特征名称
左车宽线特征名称
右车宽线特征名称
5.创建“法规线几何集名称”几何图形集，并且定义工作对象
6.确认地面法线方向和车后方向，已知以右眼点和空在地面求得地面法线方向，法线方向和xyz轴做吸附，接近的取近似的xyz正负方向，作为车辆上方向
7.已知两个镜片特征，眼点位于后视镜后方，确定车辆粗略后方向，具体后方向由左车宽线决定，通过左右车宽线，也可以求得车辆左方向和右方向
8.获取左镜片在法线方向上的里地面最远的距离点，创建该点，命名为“镜片极值点”，并测得到地面的距离（极值点到地面距离），将“镜片极值点”特征对象设置为隐藏
9.以右眼点为基础，做到空载地面的投影点，该投影点在做到左车宽线上的投影点，分别命名为“眼点到地面投影点”和“地面点到左车宽线投影点”
10.参考“地面点到左车宽线投影点”，做点“左延长线端点”，点类型是曲线上，方向是左车宽线，曲线上的距离距离24000mm，如果“左延长线端点”没有在车后方向，反转方向，重新创建
11.连接“地面点到左车宽线投影点”和“左延长线端点”，做直线“左车宽线延长线”，此时后方向应与“左车宽线延长线”方向相同
12.创建距离“地面点到左车宽线投影点”4000mm的点，方向为车辆后方向，命名为“左法规点1”
13.创建距离“左法规点1”1000mm的点，方向为车辆左方向，命名为“左法规点2” 
14.创建点，距离为“极值点到地面距离”，参考点为“左法规点1”，方向为“地面法线方向”，命名为“左法规点3”
15.创建距离“左法规点1”16000mm的点，方向为车辆后方向，命名为“左法规点4”
16.创建距离“左法规点4”4000mm的点，方向为车辆左方向，命名为“左法规点5”
17.创建点，距离为“极值点到地面距离”，参考点为“左法规点4”，方向为“地面法线方向”，命名为“左法规点6”
18.以此连接左法规点，1和2，命名为“左法规线1”；1和3，命名为“左法规线2”；4和5，命名为“左法规线3”；4和6，命名为“左法规线4”；1和4，命名为“左法规线5”；2和5，命名为“左法规线6”；
19.已知“眼点到地面投影点”，创建“地面点到右车宽线投影点”，根据上面创建左法规点和左法规线，创建右法规点和右法规线

补充：
现在 左/右法规点1 和 左/右法规点4 的创建逻辑是：
先创建基准投影点
左侧用：
地面点到左车宽线投影点
右侧用：
地面点到右车宽线投影点
左右分别创建车宽线延长线
左侧：
左车宽线延长线
右侧：
右车宽线延长线
延长方向会尽量与车辆后方向一致。
法规点1优先在对应延长线上取点
以对应投影点为参考点，沿对应车宽线延长线取距离 4000mm 的点：
左法规点1 / 右法规点1
法规点4优先在对应延长线上取点
同样以对应投影点为参考点，沿对应车宽线延长线取距离 20000mm 的点：
左法规点4 / 右法规点4
这里的 20000mm = 4000mm + 16000mm，等价于原需求中“法规点4距离法规点1再往后 16000mm”。
如果第一次方向反了
代码会检查：
法规点1 - 投影点
这个方向是否和 车辆后方向 同向。
如果不是同向，就删除刚创建的点1和点4，然后反转曲线取点方向重新创建。
如果曲线上取点失败
才回退到旧逻辑：
法规点1 = 投影点 + 车辆后方向 * 4000
法规点4 = 投影点 + 车辆后方向 * 20000
所以正常情况下，点1和点4应该落在对应的 左/右车宽线延长线 上。

第二部分：创建参数化后视镜
1.创建“参数化后视镜”几何图形集，并且定义工作对象
2.创建四个参数参数类型为角度具有单值，名称分别为“左镜片水平旋转角度”，“左镜片竖直旋转角度”，“右镜片水平旋转角度”，“右镜片竖直旋转角度”，角度默认为0deg
3.创建左镜片重心点，并命名为“左镜片重心点”
4.过重心点，作左镜片的法线，参考点为重心，起点为-100mm终点为100mm，命名为“左镜片法线”
5.求左镜片法线与左镜片的交点，命名为“左镜片法线与镜片交点”
6.创建点，左镜片法线与镜片交点向镜片球心方向，沿着左镜片的法线偏移9.5mm，点命名为“左镜片旋转中心”
7.根据“左镜片旋转中心”和“左镜片法线”创建一个垂直于法线的平面，命名为“旋转参考平面”
8.根据“旋转参考平面”创建草图，根据草图的竖直方向和水平方向创建两条过“左镜片旋转中心”的过程直线，直线长各200mm，参考地面法线方向来判断是水平轴还是竖直轴；隐藏草图，并根据草图中的两条过程直线创建3D特征，命名为“左镜片水平旋转轴”和“左镜片竖直旋转轴”
9.创建旋转，旋转元素为左镜片，旋转轴为“左镜片水平旋转轴”，参数绑定为参数“左镜片水平旋转角度”，旋转特征命名为“左镜片仅水平旋转”，隐藏初始元素
10.创建旋转，旋转元素为“左镜片仅水平旋转”，旋转轴为“左镜片竖直旋转轴”，参数绑定为参数“左镜片竖直旋转角度”，旋转特征命名为“左镜片旋转”，隐藏初始元素
11.参考“左镜片旋转”的流程，创建“右镜片旋转”
12.将“参数化后视镜”几何图形集中除了“左镜片旋转”“右镜片旋转”所有的特征都隐藏

第三部分 临时法规反射取点测量

【先执行左镜片测量，后执行右镜片测量】

旋转角度右和下是角度正方向，左和上是角度负方向

左镜片需要调两个参数：
    左镜片水平旋转角度
    左镜片竖直旋转角度

搜索范围：
    -2.0° 到 +2.0°
    步长 0.2°

左右镜片独立搜索：
    左镜片只调整“左镜片水平旋转角度”和“左镜片竖直旋转角度”
    右镜片只调整“右镜片水平旋转角度”和“右镜片竖直旋转角度”

角度组合搜索顺序：
    优先 max(abs(水平角度), abs(竖直角度)) 最小
    其次 abs(水平角度) + abs(竖直角度) 最小
    再其次按水平角度绝对值、竖直角度绝对值、角度实际值排序

边界来源：
    左镜片测量时，基于当前角度下的“左镜片旋转”提取“左镜片临时边界”
    右镜片测量时，基于当前角度下的“右镜片旋转”提取“右镜片临时边界”

通过标准：
    每个临时法规反射取点到当前镜片边界的最小距离均大于等于3mm，且点在当前镜片面上
    若所有角度组合均不满足，通过结果记为失败，但仍回退到0度姿态创建临时反射取点；镜片过小时允许这些回退点位于镜片外，用于后续正式法规反射取点绘制

伪代码：
for h in angle_values:
    for v in angle_values:
        创建“左镜片临时法规反射取点”几何图形集，并定义工作对象

        设置 左镜片水平旋转角度 = h（初始默认为0）
        设置 左镜片竖直旋转角度 = v（初始默认为0）
        part.Update()

        获取当前 左镜片旋转 的球心
        获取当前 左镜片旋转 的半径

        根据球心、半径、左法规点1-6、左右眼点
        用算法求左镜片12个临时法规反射取点

        创建这些临时点，命名参考“左/右眼左法规反射取点1”

        提取左镜片的边界，命名为“左镜片临时边界”

        对点进行分组：
        1.右眼左法规反射取点1、左眼左法规反射取点1
        2.右眼左法规反射取点2、左眼左法规反射取点2
        3.右眼左法规反射取点5、左眼左法规反射取点5
        4.左眼左法规反射取点3、左眼左法规反射取点6（右镜片：右眼右法规反射取点3、右眼右法规反射取点6）
        右眼左法规反射取点4、左眼左法规反射取点、右眼左法规反射取点3、右眼左法规反射取点6 不进入任何组

        测量每个点到左镜片边界的最小距离，同时测量每个点到镜片面的距离

        每组先筛选位于镜片面上的点
        如果任一组没有位于镜片面上的点:
            删除“左镜片临时法规反射取点”几何图形集，继续搜索下一组角度

        每组优先筛选到边界距离大于等于3mm的点，作为该组临时视野候选点
        如果某组没有到边界距离大于等于3mm的点:
            该组退回使用本组所有位于镜片面上的点，作为该组临时视野候选点

        从4组临时视野候选点中，每组取1个点，遍历所有四点组合
        将每个四点组合转换到镜片局部二维平面
        只保留凸四边形组合
        从凸四边形组合中选取面积最小的凸四边形
        该凸四边形的四个顶点作为该镜片四个最终视野点

        如果无法形成凸四边形:
            删除“左镜片临时法规反射取点”几何图形集，继续搜索下一组角度

        如果四个最终视野点到边界距离均大于等于3mm:
            记录这组角度
            保留该角度下的临时几何图形集
            记录四个最终视野点
            结束左镜片测量

        如果四个最终视野点中存在到边界距离小于3mm的点:
            删除“左镜片临时法规反射取点”几何图形集
            继续搜索下一组角度

如果所有角度组合都搜索完仍不满足:
    终端输出搜索失败
    输出搜索过程中最接近满足条件的角度组合及其最小边界距离

    设置当前水平竖直偏转角度为0
    基于0度姿态创建并保留该侧12个临时法规反射取点

    按上述分组逻辑从0度姿态的12个临时法规反射取点中选取四个最终视野点：
        每组先筛选位于镜片面上的点
        如果某组存在位于镜片面上的点:
            该组优先筛选到边界距离大于等于3mm的点，作为该组临时视野候选点
            如果该组没有到边界距离大于等于3mm的点:
                该组退回使用本组所有位于镜片面上的点，作为该组临时视野候选点

        如果某组没有位于镜片面上的点:
            该组退回使用本组所有点，作为该组临时视野候选点

        从4组临时视野候选点中，每组取1个点，遍历所有四点组合
        将每个四点组合转换到镜片局部二维平面
        只保留凸四边形组合
        从凸四边形组合中选取面积最小的凸四边形
        该凸四边形的四个顶点作为该镜片四个最终视野点

    如果能选出四个最终视野点:
        记录这四个最终视野点用于后续正式最佳视野线框
        标记为回退结果
        校核结果仍为不通过

    如果0度姿态仍无法选出四个最终视野点:
        保留0度姿态的12个临时法规反射取点
        不创建该侧最佳视野线框
        标记为回退失败
        校核结果仍为不通过
