# 后视镜项目开发文档

# 1. 项目概述

## 1.1 项目背景

外后视镜视野校核是整车外饰与布置开发中的关键校核环节。每次造型或镜片方案变化后，工程师需要在 CATIA 中依据法规要求绘制左右法规区域、构造眼点到镜片的反射关系、生成法规反射点，并检查反射点到镜片边界的间隙是否满足要求。

传统流程依赖人工在 CATIA 中逐步建点、建线、建平面、进入草图、做反射约束、测量边界间隙并整理报告。需求文档中提到，人工校核一车外后视镜法规视野需要较长时间，且不同工程师的操作习惯会造成结果差异，最终结果不一定稳定或最优。

本项目通过本地 Web 工作台、FastAPI 后端和 CATIA COM 自动化脚本，将外后视镜法规反射点校核流程工程化，实现 CATPart 上传、CATIA 状态检测、输入参数检查、自动几何构造、镜片角度搜索、间隙校验、距离标注装配、结果另存、法规/后视镜截图和 Word 报告输出。

## 1.2 现状痛点

- 人工操作链路长：需要手动绘制法规线、法规面、反射点、三角线框和间隙测量点。
- 校核结果不稳定：镜片角度调整依赖经验，人工结果不一定是可复现的最优结果。
- 数据追溯困难：CATIA 几何构造、截图、测量值和报告需要人工整理，历史结果不易归档。
- 版本迭代压力大：每版造型都要重复完整校核，需求文档估算一年约 160 小时人工投入。
- 异常定位困难：输入特征名称错误、CATIA 未打开、反射点失败等问题不易在界面中快速定位。

## 1.3 项目目标

### 1.3.1 自动化外后视镜法规视野校核

系统自动连接或启动 CATIA，打开上传的 CATPart 文件，根据输入参数几何图形集中的左右镜片、左右眼点、地面和车宽线，自动构造法规线、参数化后视镜、法规反射点和测量点间隙校验结果。

### 1.3.2 最优镜片偏转搜索

系统通过左右镜片水平/竖直旋转角度参数进行组合搜索，先按法规反射点分组生成临时视野候选点，再从四组候选点中选取面积最小的凸四边形作为最终视野点，并判断最终视野点到镜片边界的距离是否满足 3mm 要求。系统自动输出左右镜片偏移结果，例如“不偏转”“向左偏转 0.2°”“向下偏转 0.8°”等。

### 1.3.3 实时反馈与异常定位

前端日志助手通过 WebSocket 展示 16 步流程进度、CATIA 打开状态、输入检查清单和最终后视镜偏移结果。输入参数检查会逐项显示是否找到，例如输入参数几何图形集、左镜片、右镜片、左右眼点、地面和车宽线，找到显示绿色，未找到显示红色。

### 1.3.4 结果交付与归档

检测完成后，系统输出另存后的后视镜校核 CATPart、距离标注 CATPart、标注 CATProduct、截图和 Word 报告。前端支持将结果文件和报告文件保存到浏览器 IndexedDB 版本库，后续可预览、下载、删除和管理历史结果，其中 `.docx` 报告支持轻量在线预览。

# 2. 系统架构

系统采用本地单机 Web 服务架构。前端页面运行在浏览器中，后端 FastAPI 服务运行在本机，通过 COM 接口驱动同机 CATIA V5。CATIA 自动化脚本以独立子进程运行，避免 COM 或 CATIA 原生异常导致 Web 服务进程崩溃。

| 架构层次 | 组件说明 |
|---|---|
| 前端层 | `rearview_mirror/web/index.html`，单页面工作台，提供文件上传、CATIA 状态检测、设置弹窗、实时画面捕获、日志助手、版本库和结果保存。 |
| API 服务层 | `rearview_mirror/server/server.py`，FastAPI 服务，提供页面、上传、检测、状态、下载、CATIA 检测/启动和 WebSocket 日志接口。 |
| 子进程隔离层 | `rearview_mirror/server/run_algorithm_worker.py`，负责在独立 Python 进程中加载算法模块、初始化 COM、执行检测并写回 JSON 结果。 |
| 算法层 | `rearview_mirror/server/pycatia_regulation_reflection_point_detection/main.py`，核心 CATIA 自动化和几何算法实现。 |
| 数据持久层 | `session.json` 保存后端会话状态；浏览器 IndexedDB 保存前端版本库结果文件。 |
| 输出层 | 输出结果 CATPart、距离标注 CATPart、标注 CATProduct、法规视野截图、左右后视镜截图、Word 报告 `.docx` 和 JSON 结果数据。 |

# 3. 核心功能

## 3.1 CATIA 状态检测与启动

页面初始化后自动调用 `/api/catia-status` 检测当前是否存在 `CATIA.Application` COM 实例。

- CATIA 已打开：日志助手显示“CATIA 状态: 已打开”，绿色状态。
- CATIA 未打开：日志助手显示“CATIA 状态: 未打开”，并提供“打开 CATIA”和“重新检测”按钮。
- 点击“打开 CATIA”：前端调用 `/api/open-catia`，后端尝试通过 COM `Dispatch("CATIA.Application")` 启动 CATIA 并设置可见。

## 3.2 文件上传与检测启动

前端支持上传一个后视镜法规反射点检测 `.CATPart` 文件。上传文件会作为 `radar_file` 通过 `/verify` 提交给后端。后端保存到 `server/uploads/<timestamp>/` 后，进入检测流程。

文件选择框虽然配置了 `accept=".CATPart,.catpart"`，但该属性只影响文件选择器默认过滤，不作为安全校验。当前前端已增加真实文件名扩展名校验：选择文件时和点击“确认上传”时都会检查文件名是否以 `.catpart` 结尾，大小写不敏感；如果用户在系统文件选择器中切换到“所有文件”并选择了 PDF、图片、文本等非 CATPart 文件，前端会清空选择并在日志助手提示“文件类型不正确，请上传 .CATPart 文件”。后端 `/verify` 和 `/api/upload` 仍保留 `.catpart` 后缀校验，作为服务端兜底防护。

当前页面在启动检测前会请求浏览器屏幕捕获，用于在左侧预览区显示 CATIA 画面。该捕获基于浏览器 `getDisplayMedia()`，不是原生嵌入 CATIA 窗口。

## 3.3 参数设置

设置弹窗提供以下可编辑文本参数，默认值与算法常量一致，并保存到浏览器 `localStorage`：

| 设置项 | 默认值 |
|---|---|
| 输入参数几何图形集名称 | 输入参数 |
| 左镜片特征名称 | 镜片 左 |
| 右镜片特征名称 | 镜片 右 |
| 左眼点特征名称 | 左眼点 |
| 右眼点特征名称 | 右眼点 |
| 地面特征名称 | 空载地面 |
| 左车宽线特征名称 | 车宽线-左 |
| 右车宽线特征名称 | 车宽线-右 |

检测启动时，前端将这些设置随 `FormData` 一并传给 `/verify`。后端写入临时配置 JSON，worker 读取后传入 `run_rearview_analysis()`。如果某项为空，则回退到算法默认值。

## 3.4 输入检查清单

算法读取输入参数时会逐项检查并输出日志：

- 输入参数几何图形集是否存在。
- 左镜片、右镜片、左眼点、右眼点、地面、左车宽线、右车宽线是否存在。

日志格式如下：

```text
[输入检查][success] 左镜片特征名称“镜片 左”: 已找到
[输入检查][error] 右眼点特征名称“xxx”: 未找到（在几何图形集“输入参数”中未找到特征: xxx）
```

前端识别 `[输入检查][success/error]`，在日志助手中分别显示绿色或红色。若某个特征未找到，系统会继续检查后续特征，尽量一次性列出完整缺失清单。检查结束后如果存在任意缺失项，算法停止并返回失败。

## 3.5 法规线与法规点构造

算法根据输入特征自动完成外后视镜法规线准备流程：

1. 根据空载地面计算地面法线，并在接近全局 XYZ 正负轴时吸附到对应轴向，作为车辆上方向。
2. 根据镜片和眼点先计算车辆粗略后方向。
3. 根据右眼点投影到空载地面，生成眼点到地面投影点。
4. 将地面投影点分别投影到左右车宽线，生成“地面点到左/右车宽线投影点”。
5. 基于左右车宽线分别创建“左/右延长线端点”和“左/右车宽线延长线”，延长距离为 24000mm。
6. 以左车宽线延长线方向修正车辆后方向，并由左右车宽线投影点确定车辆左/右方向。
7. 左/右法规点 1 和点 4 优先在对应车宽线延长线上按 4000mm、20000mm 距离创建，确保点位落在延长线上。
8. 在车辆左右方向和地面法线方向上生成法规宽度点与高度点。
9. 连接法规点，生成左右法规线。

法规点和法规线的命名遵循算法约定，例如“左法规点1”“左法规线1”等。

## 3.6 参数化后视镜构造

系统会创建“参数化后视镜”几何图形集，并为左右镜片分别创建水平和竖直旋转角度参数：

- 左镜片水平旋转角度
- 左镜片竖直旋转角度
- 右镜片水平旋转角度
- 右镜片竖直旋转角度

算法基于镜片重心点、法线、旋转中心和旋转轴建立左右镜片旋转特征。旋转中心沿镜片法线方向偏移 9.5mm，符合需求文档中“镜片旋转点”的操作逻辑。

## 3.7 临时法规反射取点与镜片偏移搜索

左右镜片独立搜索水平/竖直旋转角度，搜索范围默认 `-2.0°` 到 `+2.0°`，步长 `0.2°`。每组角度下，算法创建临时法规反射取点，测量每个临时反射点到当前镜片边界的最小距离，并测量其到当前镜片面的距离。

临时点按镜片侧分成 4 组：

- 第 1 组：右眼/左眼对应法规反射取点 1。
- 第 2 组：右眼/左眼对应法规反射取点 2。
- 第 3 组：右眼/左眼对应法规反射取点 5。
- 第 4 组：左镜片只取左眼左法规反射取点 3/6；右镜片只取右眼右法规反射取点 3/6。

正常搜索时，每组先筛选位于镜片面上的点；如果某组没有面上点，该角度组合无效并继续搜索下一组角度。每组优先使用边界距离 `>= 3mm` 的面上点作为临时视野候选点；如果某组没有满足 3mm 的面上点，则退回使用该组所有面上点作为候选点。

算法从 4 组候选点中每组取 1 个点，遍历所有四点组合，将组合转换到镜片局部二维平面，只保留凸四边形，并选取面积最小的凸四边形作为该镜片四个最终视野点。若多个凸四边形面积相同，优先选择最终四点最小边界距离更大的组合。

通过标准：

```text
能够形成面积最小的凸四边形，且四个最终视野点到镜片边界的距离均 >= 3mm
```

如果所有角度组合都不满足，算法会输出搜索失败并回退到 `0deg/0deg` 姿态，仍创建并保留该侧 12 个临时法规反射取点。0 度回退选点时，如果某组没有位于镜片面上的点，则该组退回使用本组所有点作为候选点，再通过面积最小凸四边形方式选出四个最终视野点。回退结果用于后续正式最佳视野线框，但该侧校核结果仍记录为不通过；如果 0 度仍无法形成四个最终视野点，则跳过该侧最佳视野线框。

搜索结果会记录：

- 水平角度
- 竖直角度
- 已测试组合数
- 最小边界距离
- 最终视野点数量
- 最终视野四边形面积
- 是否通过
- 偏转说明

检测结束后，日志助手最终追加展示“后视镜偏移结果”：

```text
后视镜偏移结果
左镜片: 不偏转 / 水平 0° / 竖直 0°
右镜片: 向左偏转0.2° / 水平 -0.2° / 竖直 0°
```

## 3.8 法规反射取点与线框生成

算法根据左右眼点、左右法规点和左右镜片球心，自动创建参考平面、草图、相交线、草图反射点和正式法规反射点。

创建范围包括：

- 右眼左法规反射取点 1-6
- 右眼右法规反射取点 1-6
- 左眼左法规反射取点 1-6
- 左眼右法规反射取点 1-6

若左右镜片均完成临时反射点创建，一共生成 24 个正式反射点。若某侧镜片搜索未通过，但 0 度回退成功创建了该侧 12 个临时反射点，则正式阶段仍创建该侧对应的 12 个法规反射点，反射点允许位于裁剪镜片外的同半径镜面球面上；若某侧临时点创建失败，则跳过该侧对应反射点。

系统还会连接三角线框：

- 右眼相关线框为橙色。
- 左眼相关线框为黄色。
- 最佳视野边界线框为红色，优先使用临时搜索阶段选出的四个最终视野点；如果该侧未能选出四个最终视野点，则跳过该侧最佳视野线框，不再回退到 12 点最大面积四边形方式。

系统会根据最佳视野凸四边形采集距离标注数据：提取左右镜片边界，测量四个最佳视野边界点到对应镜片边界的最近点和距离。标注输出采用单独装配流程：

1. 先在 `output` 目录创建并另存 `Rearview_Distance_Annotations_时间戳.CATPart`，PartNumber 为 `__Rearview_Distance_Annotations__`。
2. 新建 `label_时间戳.CATProduct`，将结果 CATPart 和标注承载 CATPart 装配进去。
3. 在已装配的标注承载 CATPart 中创建“距离标注”几何图形集，生成绿色标注点、最近边界点和距离连线，线宽为 2。
4. 优先通过 CATProduct 的 `Marker3Ds` 创建 3D 文本标记，文本内容为距离结果，单位为 mm；文本位置相对两点连线中点沿车辆右方向偏移 3mm，字号设置为 8。
5. 单条标注失败时记录错误并继续创建后续标注。
6. 创建完标注后保存标注承载 CATPart，再在左右后视镜截图后保存 `label_时间戳.CATProduct`。

## 3.9 间隙校验与二次校核

间隙校验阶段会提取左右镜片边界，测量正式法规反射点到镜片边界的距离，并判断是否满足 3mm 间隙要求。

二次校核阶段会将 CATIA 测量结果与临时搜索阶段的间隙结果进行对比，输出每个点的临时距离、CATIA 距离和差值，并汇总最大距离差值。

## 3.10 截图与 Word 报告

算法会设置 CATIA 当前 3D 视图并生成截图。法规视野截图在结果另存和标注装配前生成；左右后视镜截图在标注 CATProduct 窗口中生成，以便包含标注显示状态。截图完成后生成 Word 报告 `.docx`，报告当前包含：

- 法规视野校核要求。
- 法规视野截图。
- 法规视野检查项及每条是否合格。
- 左后视镜截图。
- 右后视镜截图。
- 后视镜偏转结果。

后端 `/api/download-report` 返回 Word MIME 类型：

```text
application/vnd.openxmlformats-officedocument.wordprocessingml.document
```

前端版本库支持 `.docx` 轻量在线预览：浏览器直接解析 DOCX 内部的 `word/document.xml`、关系文件和图片资源，可展示段落、表格和报告图片；若浏览器不支持解压或解析失败，则保留下载按钮。

# 4. 完整检测流程

## 4.1 流程总览

| 步骤 | 名称 | 操作说明 |
|---|---|---|
| 第 1 步 | 连接 CATIA | 连接已打开的 CATIA，若算法执行阶段未打开则尝试启动。 |
| 第 2 步 | 打开 CATPart | 打开用户上传的 CATPart 文件。 |
| 第 3 步 | 读取后视镜 Part | 查找输入参数几何图形集。 |
| 第 4 步 | 读取镜片与眼点输入 | 检查左右镜片、左右眼点、地面和车宽线。 |
| 第 5 步 | 确认车辆方向 | 根据地面、眼点、镜片和车宽线计算车辆粗略方向，地面法线按需吸附全局轴，后方向由车宽线延长线修正。 |
| 第 6 步 | 创建参数化后视镜 | 创建旋转参数、旋转中心、旋转轴和左右镜片旋转特征。 |
| 第 7 步 | 隐藏过程特征 | 隐藏构造过程中的辅助点、线、平面和草图。 |
| 第 8 步 | 法规线创建 | 创建左右法规点和法规线。 |
| 第 9 步 | 法规反射取点 | 创建临时反射点、搜索镜片偏移角度、创建正式法规反射点。 |
| 第 10 步 | 间隙校验 | 测量反射点到镜片边界距离并判断是否满足 3mm。 |
| 第 11 步 | 二次校核 | 对比临时搜索距离与 CATIA 正式测量距离。 |
| 第 12 步 | 法规视野截图 | 按法规视野方向截取法规线总体图片。 |
| 第 13 步 | 结果另存 | 将后视镜校核 CATPart 另存到 output 目录。 |
| 第 14 步 | 创建标注装配 | 创建标注 CATPart，装配结果 CATPart 和标注 CATPart，并生成距离标注。 |
| 第 15 步 | 左/右后视镜截图 | 激活 CATProduct 窗口，截取左右后视镜截图。 |
| 第 16 步 | 保存校核文件与标注装配 | 保存后视镜校核 CATPart 和 `label_时间戳.CATProduct`。 |

## 4.2 前端状态展示

日志助手顶部固定显示 16 步流程状态，不会被后续日志顶出可视区域。状态包括：

- 待执行
- 执行中
- 已完成
- 异常
- 已跳过

输入检查、CATIA 状态、后视镜偏移结果和保存提示作为普通日志消息显示在流程状态块下方。

## 4.3 异常处理

| 异常类型 | 当前处理方式 |
|---|---|
| CATIA 未打开 | 页面加载时提示，并提供打开 CATIA 按钮；算法执行时也会尝试连接或启动。 |
| 上传文件类型错误 | 前端在选择文件和确认上传时校验 `.CATPart/.catpart` 后缀，错误时清空选择并提示；后端再次校验后缀，拒绝非 CATPart 文件。 |
| 输入参数几何图形集未找到 | 日志助手红色提示，算法停止。 |
| 某个输入特征未找到 | 继续检查其余特征，最终统一报“输入检查未通过”。 |
| 检测流程正在运行 | 后端返回 409/503，避免重复启动 CATIA 自动化。 |
| 子进程崩溃 | 后端保留最后输出，返回“检测子进程崩溃或未返回结果”。 |
| 报告未生成 | `/verify` 返回失败，提示“检测完成但未生成报告文件”。 |

| 右车宽线 | 车宽线-右 | 右侧车宽参考线。 |

## 5.3 固定算法参数

| 参数 | 当前值 | 说明 |
|---|---:|---|
| 镜片边界间隙阈值 | 3mm | 反射点到镜片边界需大于等于该值。 |
| 镜片角度搜索范围 | ±2.0° | 左右镜片独立搜索。 |
| 镜片角度搜索步长 | 0.2° | 水平、竖直角度组合搜索。 |
| 镜片旋转中心偏移 | 9.5mm | 沿镜片法线方向偏移。 |
| 后视镜截图视距 | 644mm | 左右后视镜截图时写入 CATIA `FocusDistance`。 |
| 法规视野截图视距 | 30000mm | 按车前端到法规线最远端约 24000mm 和 1.25 倍留边系数推算。 |
| 车宽线延长距离 | 24000mm | 左/右车宽线延长线创建距离。 |
| 地面法线轴向吸附角度 | 5° | 地面法线接近全局 XYZ 正负轴时吸附。 |
| 标注文本字号 | 8 | 3D 文本标注字号。 |
| 标注文本偏移 | 3mm | 标注文本相对两点中点沿车辆右方向偏移。 |

# 10. 后续优化建议

## 10.1 报告内容增强

当前 Word 报告已从 Excel 输出切换为 `.docx`，并已包含当前法规视野校核报告的主要内容。后续可继续增强样式和判定表达：

| 校核条目 | 法规要求 | 检查参数 | 实际结果 | 是否满足 |
|---|---|---|---|---|
| 左镜片间隙 | 所有反射点到边界距离 >= 3mm | 最小距离 | xx mm | 满足/不满足 |
| 右镜片间隙 | 所有反射点到边界距离 >= 3mm | 最小距离 | xx mm | 满足/不满足 |
| 左镜片偏移 | 找到满足间隙的最小偏转组合 | 水平/竖直角 | x° / y° | 满足/不满足 |
| 右镜片偏移 | 找到满足间隙的最小偏转组合 | 水平/竖直角 | x° / y° | 满足/不满足 |

Word 中可进一步增加绿色/红色单元格，用于展示满足/不满足状态。

## 10.2 CATIA 视图恢复

截图逻辑会设置 CATIA 当前 3D 视图。建议后续在截图前保存 `Viewpoint3D` 的 Origin、SightDirection、UpDirection 和 FocusDistance，截图后恢复，避免影响用户原始视角。

## 10.3 捕获体验优化

当前左侧 CATIA 画面基于浏览器窗口捕获。后续可增加设置项：

- 不捕获 CATIA 画面，直接运行检测。
- 捕获整个显示器而不是窗口，减少系统对 CATIA 窗口布局的影响。
- 检测结束后保留或停止画面捕获。

## 10.4 内后视镜扩展

需求文档中同时提到内后视镜校核，包括内镜最高点、路基面中心线、内后视镜镜片数据、后风挡和黑边遮挡等参数。当前项目主要实现外后视镜法规反射点校核，后续可基于现有架构扩展内后视镜模块。
