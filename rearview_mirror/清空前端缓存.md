# 清空前端缓存说明

## 什么时候需要清空

如果修改了前端默认检测设置，但页面中仍然显示旧内容，通常是浏览器本地缓存了旧设置。

常见表现：

- 检测设置中仍显示旧的特征名称。
- 修改 `DEFAULT_ALGORITHM_SETTINGS` 后页面没有变化。
- 重新打包 exe 后，前端仍沿用之前保存过的设置。

原因是前端会优先读取浏览器 `localStorage` 中保存过的用户设置；只有没有本地设置时，才会使用代码中的默认值。

## 推荐方式：只清除检测设置

打开前端页面，例如：

```text
http://localhost:8000
```

按 `F12` 打开浏览器开发者工具，进入 `Console` 或 `控制台`，执行：

```js
localStorage.removeItem("rearview_algorithm_feature_names");
location.reload();
```

执行后页面会刷新，检测设置会重新使用代码中的默认值。

## 清除全部相关前端设置

如果需要同时清除画面捕获相关设置，可执行：

```js
localStorage.removeItem("rearview_algorithm_feature_names");
localStorage.removeItem("rearview_capture_before_detection");
localStorage.removeItem("rearview_auto_stop_capture");
location.reload();
```

## 通过浏览器设置清除

也可以在浏览器设置中清除站点数据。

以 Microsoft Edge 为例：

1. 打开浏览器设置。
2. 进入 `隐私、搜索和服务`。
3. 找到 `Cookie 和站点权限` 或 `查看所有 Cookie 和站点数据`。
4. 搜索并选择 `localhost`。
5. 删除 `localhost` 对应的站点数据。
6. 回到前端页面并刷新。

注意：只清除“缓存的图片和文件”通常不会清除 `localStorage`，需要清除 `Cookie 和其他站点数据` 或 `站点数据`。

## localhost 是什么

`localhost` 表示本机前端服务地址。

本项目本地访问通常是：

```text
http://localhost:8000
```

因此删除 `localhost` 的站点数据，就是清除当前本机前端页面保存过的设置。
